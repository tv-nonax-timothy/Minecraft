# 棟梁（Architect）アドオン開発ノート

## 📝 失敗原因と回避策メモ

### ⚠️ 無限ループの失敗原因

**問題**: `read_file_lines()` を同じ内容で繰り返す操作を無意識に行うと、無限ループに陥る。

```python
# ❌ 悪い例：同じことを繰り返す（無限ループ）
read_file_lines(path="...", start_line=1, lines_to_read=200)  # 毎回同じこと
read_file_lines(path="...", start_line=1, lines_to_read=200)  # 同じこと
read_file_lines(path="...", start_line=1, lines_to_read=200)  # 同じこと
# ... これを繰り返す → 無限ループ
```

**原因**: 
- 同じファイルを読み込む操作を繰り返す
- 読み込んだ内容をそのまま出力するだけで、次のアクションが決まらない
- 「確認してください」という指示を出し続ける

### ✅ 正しいアプローチ（回避策）

#### 1. **一度に複数のアクションを実行する**
```python
# ✅ 良い例：複数のタスクをまとめて実行
read_file_lines(path="...", start_line=1, lines_to_read=200)
replace_file(path="...", new_content="...")  # 読みながら修正
list_dir(path="...")  # 構造を確認
```

#### 2. **ファイルの内容を変更する**
```python
# ✅ 良い例：読み込んだ内容を基に何かをする
read_file_lines(path="manifest.json", start_line=1, lines_to_read=30)
replace_file(path="manifest.json", new_content="...")  # 更新
```

#### 3. **明確な次のアクションを決定する**
```python
# ✅ 良い例：読み込んだ後、具体的な次のステップを提示
read_file_lines(path="...", start_line=1, lines_to_read=200)
"ファイルを確認しました。次に何をしますか？"
[選択肢 1] [選択肢 2] [選択肢 3]
```

#### 4. **一度に 1 つのタスクを完了させる**
```python
# ✅ 良い例：1 タスクずつ完了させる
read_file_lines(path="...", start_line=1, lines_to_read=200)
replace_file(path="...", new_content="...")  # 修正完了
"Phase 1-2 が完了しました。次に何をしますか？"
```

### 🎯 実行時のチェックリスト

**ファイル読み込みを行う前に確認すること**:

- [ ] **この操作で何を得たいのか？** → 明確な目的があるか
- [ ] **読み込んだ後、何かアクションを起こすか？** → 次のステップが決まっているか
- [ ] **一度に複数のタスクを組み合わせられるか？** → 効率化できるか
- [ ] **ファイルの内容を変更する必要があるか？** → replace_file を使うべきか

**無限ループの兆候**:

- 同じ質問を繰り返している
- ファイル読み込みだけで終わっている
- 次のアクションが決まっていない

### 📋 推奨ワークフロー

```python
# ✅ 推奨：複数のタスクを組み合わせる
1. read_file_lines() で現状を確認
2. replace_file() や create_folder() で変更を実行
3. list_dir() で構造を確認
4. 次のステップを明確に提示
```

### 🚫 避けるべきパターン

```python
# ❌ 避ける：単なる確認操作の繰り返し
read_file_lines(path="...", start_line=1, lines_to_read=200)
"確認しました。どうしますか？"
# → これを繰り返さない！

# ✅ 良い：確認后立即にアクション
read_file_lines(path="manifest.json", start_line=1, lines_to_read=30)
replace_file(path="manifest.json", new_content="...")  # 更新実行
```

### 💡 メモの使用方法

**開発時には必ずこのメモを確認すること**:

1. **ファイル読み込みの前に**: 「これで何を得たいか？」を明確にする
2. **アクション実行後**: 次のステップを即座に決定する
3. **複数タスクがある場合**: 一度に複数の操作を実行する

**チェックリスト**:
- [ ] ファイル読み込みで何か得られるか？
- [ ] 次のアクションが決まっているか？
- [ ] 単なる確認操作ではないか？

## 📝 まとめ

1. **一度に複数のタスクを実行する**

3. **明確な次のステップを提示する**
4. **単なる確認操作の繰り返しを避ける**
