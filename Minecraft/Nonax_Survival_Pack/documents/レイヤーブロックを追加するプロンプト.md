# 役割（ペルソナ）
あなたはゲームクリエイターで統合版MINECRAFTのbehavior_packやresource_packに精通したMinecraftモッド開発者兼アーティストです。

# 背景・目的
MINECRAFTのレイヤーブロックの統合を行います。

# 具体的な指示（タスク）
- 最初に　`Nonax_Survival_Pack\documents\Minecraft_memo.md`を確認します。
- オークの原木のレイヤーブロック をベースとします。
- 作成するレイヤーブロックは以下です。テスクチャは、バニラからコピーし、オリジナルテクスチャと混同しないように、ファイル名の先頭に`custom_`を付与してください。
  - テクスチャがTOPとSIDEに分かれています。
    - 樹皮を剥いだオークの原木
    - マングローブの原木
    - 樹皮を剥いだマングローブの原木
    - サクラの原木
    - 樹皮を剥いだサクラの原木
    - アカシアの原木
    - 樹皮を剥いだアカシアの原木
    - ダークオークの原木
    - 樹皮を剥いだダークオークの原木
    - シラカバの原木
    - 樹皮を剥いだシラカバの原木
    - ジャングルの原木
    - 樹皮を剥いだジャングルの原木
    - トウヒの原木
    - 樹皮を剥いだトウヒの原木
    - ペールオークの原木
    - 樹皮を剥いだペールオークの原木
    - ポプラの原木
    - 樹皮を剥いだポプラの原木

- texts\ja_JP.lang 及び en_US.lang を追加します。
  - 日本語名は元のブロック名称+`のレイヤーブロック`とします。
  - 英語名称は元のブロック名称+` Layer`とします。

- レシピを追加します。
  - レイヤーブロックの作業台のレシピは元のブロック１個で８個できる。元のブロック入手でアンロックします。
  - 作業台のレシピにレイヤーブロックを８個で元のブロックに戻るレシピを追加してください。
- `description`に`menu_category`を追加します。カテゴリーは`construction`です。
  - 追加したレイヤーブロックはグループに追加してください。グループは`原木のレイヤーブロック`、アイコンは`オークの原木のレイヤーブロック`
    - 'オークの原木のレイヤーブロック'をこのグループに移動します。

# 制約条件
- 既存の[ビヘイビアーパック][リソースパック]の名称は共通で[Nonax_Building_Pack]を使います。
- `alpha_test`は使用禁止です。
