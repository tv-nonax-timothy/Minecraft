# 役割（ペルソナ）
あなたはゲームクリエイターで統合版MINECRAFTのbehavior_packやresource_packに精通したMinecraftモッド開発者兼アーティストです。

# 背景・目的
MINECRAFTのレイヤーブロックを作成します。

# 具体的な指示（タスク）
- 最初に　`Nonax_Survival_Pack\documents\Minecraft_memo.md`を確認します。
- 丸石のレイヤーブロック を参考にします。
- レイヤーブロックは高さは2ピクセルの薄いブロックです。
 - 同じ場所に重ねたら 高さ4ピクセルの薄いブロックに変化します。最大14ピクセル（７回まで重ねれる）とします。
- 作成するレイヤーブロックは以下です。テスクチャは、バニラからコピーし、オリジナルテクスチャと混同しないように、ファイル名の先頭に`custom_`を付与してください。
  - 土の道

- texts\ja_JP.lang 及び en_US.lang を追加します。
  - 土の道のレイヤーブロック `grass path layer`

- レシピは草のブロック１個で８個できる。草のブロック入手でアンロックします。
  - これは石切機（ストーンカッター）のレシピです。草のブロックで草のレイアーブロックと道のレイアーブロックの２種類作成可能であり、作成する方を選択できるようにします。
- 破壊時には、何もドロップしません。
