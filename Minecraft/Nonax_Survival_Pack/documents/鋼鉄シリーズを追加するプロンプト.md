# 役割（ペルソナ）
あなたはゲームクリエイターで統合版MINECRAFTのbehavior_packやresource_packに精通したMinecraftモッド開発者兼アーティストです。

# 背景・目的
MINECRAFTの鋼鉄シリーズを追加します。

# 具体的な指示（タスク）
- 最初に　`Nonax_Survival_Pack\documents\Minecraft_memo.md`を確認します。
- `鋼鉄のブロック`のテスクチャを作成しました。
  - `Nonax_Survival_Pack\resource_pack\Nonax_Building_Pack\textures\nonax\blocks\custom_steel_block.png`
  - `Nonax_Survival_Pack\resource_pack\Nonax_Building_Pack\textures\terrain_texture.json` にも追加してください。
- ブロックのジオメトリを作成します。
  -  ファイル名は`Nonax_Survival_Pack\resource_pack\Nonax_Building_Pack\models\blocks\nonax_block.geo.json`とします。
  - `identifier` は  `geometry.nonax_block`　とします。
  - 16 x 16 x 16 のブロックです。
- `鋼鉄のブロック`を作成します。
  - `geometry.nonax_block`ブロックのジオメトリを使ったブロックです。
  - テスクチャは`鋼鉄のブロック`を全面に貼ります。
- `鋼鉄のインゴット`のテクスチャを作成しました。これはアイテムです。
  - `Nonax_Survival_Pack\resource_pack\Nonax_Building_Pack\textures\nonax\items\custom_steel_ingot.png`
  - item_texture.jsonに追加してください。（なければ作成してください。
- `木炭と鉄の原石`のテスクチャを作成しました。これはアイテムです。
  - `Nonax_Survival_Pack\resource_pack\Nonax_Building_Pack\textures\nonax\items\custom_mixed_iron_ore.png`
  - item_texture.jsonに追加してください。（なければ作成してください。
- `Nonax_Survival_Pack\behavior_pack\Nonax_Building_Pack\blocks\steel_block.json`を作成します。
  - テスクチャは、鋼鉄のブロックです。
- レシピを追加します。
  - 作業台のレシピ 木炭と鉄の原石を1:1で`木炭と鉄の原石`ができます。レシピの開放は鉄の原石です。`description`に`menu_category`を追加します。カテゴリーは`items`です。
  - かまどのレシピ `木炭と鉄の原石`を焼くと、`鋼鉄のインゴット`が精錬できます。
  - 作業台のレシピ `鋼鉄のインゴット`　９個で、`鋼鉄のブロック`ができます。レシピの開放は鉄の原石です。`description`に`menu_category`を追加します。カテゴリーは`construction`です。
